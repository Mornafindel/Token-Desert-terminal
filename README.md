# Token-Desert-terminal
# 符号的代价：算力废墟与语义坍缩
> **The Price of Symbols: Compute Ruins and Semantic Collapse**
> 
> 一个基于先锋虚构设计（Speculative Design）与 Three.js 的交互式 MVP 叙事实验原型。

---

## 📌 项目概述 (Overview)

《符号的代价》探讨了在后人类算力霸权语境下，**“高成本母语”** 与 **“低成本极简字符”** 之间的语言经济学博弈。

玩家饰演一个在冷冻废墟中苏醒的虚拟实体，面前是封闭的系统闸门与受限的算力资源（Token）。玩家必须在消耗高额 Token 的“完整母语精准渲染”与低成本但高风险的“极简字符盲测”之间做出抉择——后者极易引发 AI 算法幻觉，在三维空间中将网格撕裂为充满攻击性的**几何畸变怪物**。

---

## ⚙️ 核心机制与流程 (Core Mechanics & Gameplay Loop)

项目的交互逻辑基于一个动态状态机与概率博弈模型：

1. **资源与状态系统**：
   - `Token 余额`：初始 60 Token（低于母语解密所需的 80 Token，迫使玩家先进行极简字符博弈）。
   - `异化值 (Corruption Index)`：初始 0%，每次触发 AI 幻觉累积 +30%。

2. **双重交互策略**：
   - **策略 A：旧时代母语 (High Cost, Guarantee)**
     - 消耗 **80 Token**。
     - 100% 成功率：精准解析语义，在 3D 场景中渲染出**【金色密钥实体】**，靠近闸门即可成功解锁逃生。
   - **策略 B：未来极简字符 (Low Cost, High Risk)**
     - 消耗 **5 Token**。
     - **20% 概率（幸运匹配）**：生成【临时密钥】或获得 +30 Token 算力补充。
     - **80% 概率（AI 算力幻觉）**：语义发生断裂，算力在空间中实时渲染出【红色顶点撕裂/抖动的畸变怪物】，怪物开始追逐玩家。若玩家被触碰则直接死亡。

3. **终局与分支闭环**：
   - **胜利分支**：拾取密钥并前往闸门，闸门升起重见天日。
   - **失败分支**：玩家被怪物捕获；或异化值达到 **100%** 触发系统彻底失语（画面崩塌乱码）。

## 🎨 视觉与技术实现 (Tech Stack & Architecture)

* **交互架构**：单文件 WebGL 原型 (`index.html`)，无需繁重的编译环境，双击即可在浏览器运行。
* **渲染引擎**：**Three.js (WebGL)**，采用基础几何体与低多边形（Low-Poly）线框美学。
* **特效实现**：
  * **Shader 几何畸变**：利用动画循环中的顶点噪声位移（Vertex Jitter / Noise Deformation），实时呈现算力失控带来的怪物网格撕裂感。
  * **CRT 赛博终端 UI**：配合 CSS3 滤镜实现扫描线（Scanline）与故障抖动（Glitch）视效。
* **生成工作流**：基于 **Cursor (Claude 3.5 Sonnet / Composer)** 提炼专业 Prompt 进行 Rapid Prototyping 开发。
