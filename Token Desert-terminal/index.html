// GATE-07 操作说明

1. 点击右侧 3D 画面聚焦，用 WASD 或 方向键 移动绿色玩家。

2. 初始只有 60 Token，不够直接买 策略 A 母语（80 Token）。需先用极简字符博弈补给。

3. 策略 B 极简字符：消耗 5 Token。20% 成功：随机获得金色钥匙或 +30 Token 补给；80% 生成红色畸变怪物并追逐，异化值 +30%。

4. 被怪物碰到即失败；异化值达到 100% 系统崩溃。可用 重置系统 重来。
